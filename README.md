# 🎬 Friday Film — Telegram Mini App & Bot

> Інтерактивний Telegram Mini App та бот для вибору фільму на вечір щоп'ятниці за допомогою космічного колеса фортуни, збереження спільних спогадів та фотографій переглядів.

---

## ✨ Можливості

- 🎡 **Колесо фортуни:**
  - Плавна фізика обертання (5 секунд, реалістичне уповільнення cubic ease-out).
  - Сектори з повними постерами фільмів (низом до центру), неонові роздільники.
  - Гучний та реалістичний звук клікера казино (Web Audio API) при проходженні кожного фільму.
  - Центральна кнопка запуску та фіксований неоновий вказівник знизу.
  - Зсувна скляна шторка списку фільмів.

- 🍿 **Список фільмів («Фільми на вечір»):**
  - Сітка карток у 2 просторі колонки з пропорцією постера `2:3`.
  - Аватарка учасника, що запропонував фільм, у неоновому обідку.
  - Перегляд фільму: натискання відкриває фільм по центру екрана зі збільшеним постером та розмиттям фону (блюром).
  - Можливість видалення фільму з вікном підтвердження.

- 🔎 **Додавання фільмів та TMDB:**
  - Мультимовний живий пошук фільмів (українська, англійська, російська) через TheMovieDB API.
  - Автоматичне завантаження офіційних постерів у високій якості (500w).
  - Можливість ручного завантаження постера з пристрою, якщо фільм не знайдено.
  - Анімація прильоту картки фільму в колесо фортуни.

- 🏆 **Екран переможця:**
  - Відкриття картки обраного фільму на глибокому чорному тлі з зоряним небом.
  - Насичене фіолетове неонове підсвічування плашки ззаду.
  - Каскадний святковий салют (4 хвилі феєрверків та конфетті).
  - Переможні звукові ефекти.
  - Можливість одразу прикріпити спільні фото перегляду.

- 🕰 **Вкладка «Спогади» (Історія переглядів):**
  - Хронологічна стрічка всіх переглянутих фільмів з датами та авторами.
  - Галерея спільних фотографій (до 3 фото на подію) з можливістю повнорозмірного перегляду.
  - Можливість додавати спільні фото в будь-який момент.
  - Кнопка **«➕ Створити спогад»** для ручного додавання спогаду (вибір дати, пошук фільму, прикріплення фото).
  - Кнопка видалення спогаду з діалогом підтвердження.
  - Завантаження фотографій одним ZIP-архівом або всіх спогадів одразу.
  - Фірмовий саундтрек при переході у спогади.

## 🛠 Стек технологій

- **Frontend:**
  - Vanilla JavaScript (ES6+), HTML5 Canvas, Web Audio API
  - Liquid Glass UI (iOS style, `backdrop-filter: blur`, неонові акценти `#A855F7`, `#000000`)
  - Telegram WebApp SDK integration
- **Backend:**
  - Python 3.9+
  - FastAPI + Uvicorn (REST API)
  - aiogram 3.x (Telegram Bot)
  - SQLite + aiosqlite (асинхронна база даних)
  - aiohttp (асинхронні запити до TMDB API)

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/l-2KIRA-l/friday-film.git
cd friday-film
```

### 2. Створення віртуального оточення
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Налаштування змінних оточення
Створіть файл `.env` на основі `.env.example`:
```bash
cp .env.example .env
```
Заповніть ваші ключі у `.env`:
```env
BOT_TOKEN=ваш_токен_telegram_бота
ADMIN_TELEGRAM_ID=ваш_telegram_id
TMDB_API_KEY=ваш_tmdb_api_key
WEBAPP_URL=https://ваш-домен-або-ngrok.com
```

### 4. Запуск сервера
```bash
python backend/main.py
```
Сервер запуститься на `http://0.0.0.0:8080`, підніме REST API та Telegram-бота одночасно.

1. У BotFather створіть нового бота або скористайтеся наявним.
2. Встановіть Menu Button з типом Web App та посиланням на ваш `WEBAPP_URL`.
3. Додайте бота до вашої сімейної або дружньої групи!
